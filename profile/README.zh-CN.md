# TradingKnowledgeHub（TKH）

[English](https://github.com/TradingKnowledgeHub)

**把交易学习资料转化为自己的理解、知识和交易方法。**

TKH 将股票与期权教育视频、文章与你的笔记、问题和 AI 辅助研究连接起来，让学习成果能够保存、重温，并逐步整理成自己的知识与 Playbook。

## 学习、提问、积累

- **带着目标学习。** 探索学习材料，记录对你重要的要点和问题。
- **深化理解。** 结合材料和笔记展开讨论，区分来源作者的解释、AI 输出和自己的判断。
- **积累可复用的成果。** 将有价值的理解整理为个人 Wiki 和 Playbook，保留可回查的引用，并持续改进。

哪些结论值得保留、哪些方法适合自己，由你决定。

## 当前阶段

**持续开发中。** TKH 正围绕“学习到知识”的流程持续完善，目前此处尚不提供公开安装或测试版本。

## 与 TAS、TAD 的关系

- **[TradingAlphaSystem（TAS）](https://github.com/TradingAlphaSystem)**：规划中的个人交易进化工作台，连接交易分析、知识学习与方法应用。
- **[TradingAlphaDNA（TAD）](https://github.com/TradingAlphaDNA)**：帮助用户从股票与期权交易记录中复盘学习。
- **TKH**：帮助用户从教育材料中学习，形成个人知识与 Playbook。

跨产品集成仍在开发与评估中。
